🚀 HIZLI BAŞLANGIÇ
================================================================================

1. Projeyi çıkart ve dizine gir:
   unzip sikayet-platform.zip
   cd sikayet

2. Bağımlılıkları yükle:
   composer install

3. Ortam ayarlarını yapılandır:
   cp .env.example .env
   php artisan key:generate

4. .env dosyasında database ayarlarını düzenle:
   DB_DATABASE=sikayet
   DB_USERNAME=root
   DB_PASSWORD=

5. Veritabanını oluştur ve doldur:
   php artisan migrate --seed

6. Storage link oluştur:
   php artisan storage:link

7. Sunucuyu başlat:
   php artisan serve

8. Tarayıcıda aç:
   http://localhost:8000
